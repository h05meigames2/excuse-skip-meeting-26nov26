One razor-sharp line, 200 characters or fewer, that gets you out of a pointless
work meeting or Zoom call — an entry for the
[make.fun bounty](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163).

## The entry

> I didn't skip the meeting — my calendar read the invite, saw no agenda, and declined on my behalf. It has boundaries I can only dream of.

## How it works

`main.py` (Python 3, stdlib only, no network) writes the single-line excuse to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), asserting it
is exactly one line of 1–200 characters.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
